# 今、何から逃げたい？

都市の中で一時的に落ち着ける場所とルートを探す、スマートフォン向けWebアプリです。

## 何をするのか

利用者が「人混み」「騒音」「疲れ」「一人になりたい」など、今の状態を選びます。
青山・表参道・渋谷周辺の空間データから、5〜15分で歩ける「回復ルート」を推薦します。

目的地から探す一般的な地図ではなく、**今の気分から都市の過ごし方を探す**ことが特徴です。

## ゴール

- 30地点以上の「都市の余白」データを作成する
- 6種類の状態に対応する回復ルートを作成する
- スマートフォンで使えるWebアプリを完成させる
- GitHub Pagesで公開する
- 10〜20人に利用してもらい、使いやすさと実用性を検証する
- アプリ、データ、評価結果、卒業論文を成果物として提出する

## 成果物

1. スマートフォン向けWebアプリ
2. 都市の余白データセット（地点・評価・写真・観察メモ）
3. 状態別の回復ルート
4. 利用者アンケートと検証結果
5. 卒業論文・発表資料

## 使用ツール

- ChatGPT / Codex：設計、データ整理、分類、実装、分析
- Googleスプレッドシート：地点データの管理
- OpenStreetMap / 国土地理院地図：位置・地図情報
- HTML / CSS / JavaScript：Webアプリの制作
- Leaflet / GeoJSON：地図とルートの表示
- GitHub Pages：Web公開

## 完成までのステップ

1. 青山・表参道・渋谷に対象地域を限定する
2. 「人混み」「騒音」など利用者の状態を6種類に決める
3. 静けさ、座りやすさ、人目、緑、距離などの評価項目を作る
4. 現地調査を行い、30地点以上を記録する
5. AIを使って観察メモと場所の特徴を整理する
6. 状態・評価点・歩行時間から推薦ルールを作る
7. Webアプリに地図、ルート、写真、推薦理由を実装する
8. GitHub Pagesで公開する
9. 実際に使ってもらい、アンケートで評価する
10. 結果を分析し、アプリと卒業論文を完成させる

## 研究の問い

感情や状態を起点に都市空間を推薦することで、一般的な地図検索よりも、自分に合った一時的な回復空間を見つけやすくなるのか。
