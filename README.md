# 実測歩行データに基づく3D通学路レースシステムの設計・開発と評価

> 2026年度 卒業論文プロジェクト／IMRaD形式の研究計画（暫定版）  
> 対象：淵野辺駅北口〜青山学院大学相模原キャンパス正門（約1 kmを想定）  
> **研究状況：** 研究計画段階。2026年度のゲーム実装・定量評価・HCI実験は未実施。以下では既存実践の結果と本研究の予定を区別する。

## Abstract（研究概要）

本研究は、実在する通学路をローポリゴンの3D空間として再現し、実測歩行時間と交通信号の時間的変動を取り入れた経路レースシステムの設計・開発・評価を目的とする。対象は淵野辺駅北口から青山学院大学相模原キャンパス正門までの約1 kmとし、PLATEAU・OpenStreetMap・既存の歩行計測データを活用する。最低限、複数の実在経路、歩行・計時、信号待ち、過去ログとのゴースト対戦を実装する。距離一定速度モデル、実測区間時間モデル、信号の時間変動を扱うモデルの再現性を、独立した実測記録で比較する計画である。現時点ではゲームの開発・評価結果は得られておらず、効果の断定は行わない。

---

## I. Introduction（序論）

### 1. 研究背景と問題設定

徒歩通学の所要時間は経路の長さだけでは決まらず、信号待ち、横断条件、区間ごとの歩行特性によって変化する。経路の数値比較だけでは、信号位相などの変動によって結果が変わる過程を体験することは難しい。本研究では、実測から得られた経路特性を3Dゲームの時間・横断・競争ルールに変換し、体験と定量的比較を可能にするシステムを構築する。

### 2. 本人の先行実践

[2025年度の通学ルート最適化研究](https://github.com/furuhashilab/2025gsc-AkiraMotoyoshi) では、QGISとOpenStreetMapで経路をセクション分割し、Strava GPXで各セクションを5回以上計測したと報告されている。旧モデルでは、最短距離と最短時間は一致せず、最速経路は **A1・A2・E2** と報告された。ただし、この経路順位は信号待ちモデルを修正したうえで**再計算する対象**とする。2025年リポジトリの公開mainブランチではGPX・CSV・QGIS原本を確認できていないため、原本の所在と再利用可能性は**未確認**である。

### 3. 関連研究とそこから言えること

**Deterding et al.（2011）** はゲーミフィケーションを非ゲーム文脈にゲームデザイン要素を取り入れるものとして概念化した。この研究から、タイム、達成目標、競争などのゲーム要素を設計上の構成要素として整理できる。ただし、この定義自体は実際の交通データに基づく経路レースの有効性を保証しない。今回の成果物は独立したレースゲームでもあるため、シリアスゲームという位置づけとの区別が必要である。

**Hamari, Koivisto & Sarsa（2014）** はゲーミフィケーションの実証研究をレビューし、報告される効果が文脈や利用者などの条件によって異なると整理した。このことから、ゲーム要素の導入だけで学習効果や行動変容を主張することはできず、効果の種類に対応した評価が必要であると分かる。本研究の最小構成では人への効果ではなく、ゲーム内移動モデルの再現性を測定する。

**Rundel & De Amicis（2023）** は実在キャンパスの都市データと交通シミュレーションをゲームエンジン上で統合する構成を示した。この研究から、都市の3D化・交通再現・Unityの組合せはすでに研究対象であり、それ自体を新規性として主張できない。また、街路や横断歩道の空間的再現には補正が必要となりうる。今回の焦点は、都市モデルの表示技術ではなく、実測通学時間をゲームの経路比較・競争条件に対応づけることに置く。

**Crociani et al.（2016）** は観測された歩行者の経路選択を用いて、移動距離と混雑による時間的負担を考慮した経路選択モデルを設計・評価した。この研究から、歩行のモデル化には単純な距離以外の要因と観測データに基づく評価が必要だと分かる。一方、本研究では実在通学路の区間別所要時間を3Dレースのルールとゴーストへ転換し、その時間再現性を検証する。

**以上から導く研究上の課題：** ゲーム化、3D交通再現、実測に基づく歩行モデルにはそれぞれ先行例がある。一方、**実在通学路の区間別歩行時間・信号の時間変動を3Dレースへ組み込み、独立実測値でその所要時間特性を評価する組合せ**については、これまでの調査範囲では確認できなかった。網羅的な文献調査は未完了であり、「世界初」とは主張しない。

### 4. 研究目的・研究課題

**目的：** 実測された移動特性と信号条件を、実在通学路の3Dゲーム内に反映する方法を設計し、現実の経路所要時間の再現性を定量評価する。

**中心RQ：** 実測歩行データと交通信号の時間変動を組み込んだ3Dレースシステムは、実在する複数の通学経路の所要時間特性をどの程度再現・比較できるか。

- **RQ1：** 距離一定速度モデルと区間別実測モデルで、未使用の実測記録への予測誤差はどう異なるか。
- **RQ2：** 出発時刻・信号位相によって経路の所要時間分布と順位はどう変わるか。
- **発展RQ：** 歩きやすさ、体力、車両障害などのゲームルールを導入するとゲーム内競争結果はどう変わるか。

### 5. 新規性の候補と社会的意義

**新規性候補**は、(a) 区間別実測歩行時間の平均・ばらつきをゲームの移動モデル・ゴーストの基盤とすること、(b) 実在する複数経路と現地再計測した信号の時間変動を用いて3D経路レースを構成すること、(c) 独立実測データに基づき時間モデル間の差と限界を検証すること、の組合せである。**PLATEAU・Unity・Blender・OSMを使うこと自体は新規性ではない。**

**社会的意義として期待されること：**
1. 距離や時間の数値だけでは伝わりにくい、信号待ちや横断条件が経路に及ぼす影響を体験的に比較できる情報提示手法の提案。
2. 実際の都市データと移動ログを用い、歩行環境や交通条件の違いを地域で共有・検討するツールへの応用可能性。
3. 通学路以外の徒歩回遊や地域学習など、現実の街を題材にした体験型コンテンツへの展開可能性。

これらは**将来の社会的応用に関する見通し**であり、利用者の理解・安全意識・行動が改善されたという実証結果ではない。HCI実験は発展課題とする。

## II. Methods（研究方法：予定）

### 1. 対象・データと整備方針

| データ | 利用方法 | 確認状況と制約 |
|---|---|---|
| PLATEAU 相模原市 | 建物等の簡略3Dモデル | 既知情報ではLOD2は駅前など約0.97 km²、大部分はLOD1。対象1 kmの実ファイル照合は未確認 |
| OpenStreetMap | 道路・歩道・横断歩道・信号位置候補 | 対象範囲の位置精度・欠損は未確認 |
| 既存QGIS / GPX / CSV | 経路セクション・実測歩行時間 | 原本の所在・取得可否は未確認 |
| 信号の現地再計測 | 赤・青時間、周期、位相差 | **再計測が確定、未実施** |
| Unity | 3Dレースシステムの開発 | 表示確認は当面保留 |
| Blender | 必要な道路・小物の補正 | 建物一棟ずつの精密制作はしない |

**空間再現方針：** 建物はローポリゴンで外形・位置を概ね合わせる。優先するのは歩行可能な道路・歩道、交差点、横断歩道、信号およびルートの接続であり、全線フォトリアルなデジタルツインとは呼ばない。対象は約1 km、比較対象は実在する**2経路以上**を最低ラインとする。

### 2. 信号待ちと歩行時間のモデル

赤信号の継続時間を `T_red`、サイクル長を `C`、有効青時間を `g` とする。

- **赤で到着した場合の条件付き平均**：`E(W | 赤到着) = T_red / 2`（赤の間に一様到着する仮定）。
- **サイクル全体で一様到着する場合の無条件平均**：`d_p = (C-g)^2 / (2C) = T_red^2 / (2C)`（HCM 2000の単純化した式）。

両者を混同しない。旧研究で報告された最速経路A1・A2・E2を再計算する。また、既存GPXの区間時間に信号待ちが含まれる場合、別途信号遅延を加算して二重計上しない。

現地計測では、交差点と進行方向、観測日・時間帯、赤・青・点滅の切り替え時刻、周期、信号間位相差、押しボタンの有無、例外・観測回数を記録する。車両流は最小構成で精密に実測再現せず、簡易ギミックは現実の交通再現と区別する。

### 3. システム設計：最低実装構成（MVP）

1. 実在する2経路以上を含む約1 kmのローポリ3D通学路。
2. プレイヤーの歩行操作、経路選択、チェックポイント、スタート／ゴール、区間・全体タイムの計測。
3. 区間別実測歩行時間を反映する移動モデル。
4. 再計測された主要信号の周期・位相に基づく待機と横断。
5. 走行ログの保存と過去ログのゴースト再生。実測GPXゴーストは時刻付き原本が入手できる場合に実装する。
6. 交通条件の固定・変更と、モデル別の比較評価用ログ出力。

**MVP対象外：** 夜間モード、天候、フォトリアル建物、実測に基づく詳細な車両流、オンラインリアルタイム対戦、複雑な体力・路面モデル、HCIによる利用者評価。信号無視や危険な横断でタイムを短縮できる設計は採用しない。

**拡張優先順位：**

| 優先度 | 要素 | 方針 |
|---|---|---|
| P0 必須 | 実在経路、歩行、計時、信号、区間ログ、ゴースト | 技術評価まで完成 |
| P1 高 | 信号連動の簡易車両、リプレイ、時間分析 | 交通ギミック |
| P2 中 | 歩きやすさ、体力ゲージ、ダッシュ、ペース配分 | 実測再現モードとゲームレースモードを分離 |
| P3 発展 | リアルタイム対戦、追加ルート、HCI実験 | P0の評価完了後に検討 |

### 4. 評価方法

- **M0：** 距離 ÷ 一定歩行速度。
- **M1：** セクション別実測歩行時間（平均・ばらつき）。
- **M2：** 信号位相・周期などの時間変動を明示的に扱うモデル。
- **評価指標：** 未使用実測データに対する平均絶対誤差（MAE）、時間分布、経路順位の一致、出発時刻・信号位相による差。
- **検証上の制約：** モデル構築用と検証用の実測記録を分離する。GPS停止時間と信号待ちの定義を明確にして二重計上を避ける。
- **機能試験：** タイム計測、チェックポイント、信号制御、ゴースト同期・ログ再生、安全な横断ルールが仕様通り動作するか検証する。

M2が優れていることを事前に仮定せず、改善しなかった場合も要因・限界を分析する。

### 5. 実施順序

| Phase | 実施内容 | 到達基準 |
|---|---|---|
| **0：データ監査** | 既存GPX・CSV・QGIS原本の確認、PLATEAU・OSM対象範囲の照合、信号計測設計 | 欠損と加工範囲を特定。Unity表示確認は保留 |
| **1：再計測・再分析** | 信号周期・位相の現地計測、旧ルート順位の再計算、独立検証データの準備 | 信号・時間モデルの基礎データが揃う |
| **2：3Dゲーム実装** | 2経路、歩行・計時、信号、ログ・ゴースト、必要な3D補正 | MVPが動作する |
| **3：評価・執筆** | M0・M1・M2比較、誤差と経路順位の分析、限界の整理 | 実験結果・考察・卒論完成 |
| **4：任意拡張** | 車両流、体力、歩きやすさ、ネット対戦、HCI実験 | 必要性と残余工数に応じて判断 |

## III. Results（結果）

### 1. 既存実践で報告された結果（2025年度）

- 2025年度の先行実践では、最短距離と最短所要時間のルートが一致しないことが報告された。
- 旧モデルでの最速経路は **A1・A2・E2** とされた。
- READMEには一部信号遅延値が記載されているが、元データと算定前提は未確認であるため、本研究で再計測・再計算する。

これらは**2026年度の3Dゲームについて得られた結果ではない**。

### 2. 本研究の結果（未取得）

**現時点では未実施・未取得。** 完成後に、少なくとも以下の結果を掲載する。

| ゲーム動作 | 計時・信号・ゴースト・ログの機能試験 | 未実施 |

## IV. Discussion（考察：検討予定）

### 1. 想定する論点

- 実測区間時間・信号の時間変動をゲームへ組み込むことで、単純な距離モデルとの比較にどのような違いが生じたか。
- どの信号位相・経路条件で順位が変わるか、結果は観測データによって裏づけられるか。
- 実測GPXに含まれる停止時間の扱い、信号モデルの単純化、3D形状の省略が結果にどう影響するか。
- 一つの大学通学路を対象とした設計・評価結果を、どの範囲まで他地域に一般化できるか。

**上記は検討予定であり、結果が得られたことを意味しない。**

### 2. 社会的な応用可能性と限界

信号待ちや横断などの経路特性を操作可能な3D空間で比較することで、経路情報の提示、地域の歩行環境・交通課題の共有、体験型の地域理解などへの応用が期待される。ただし、この研究のMVPでは利用者の理解向上・安全意識・行動変容を実証しないため、社会的効果の確認は今後のHCI研究に委ねる。

### 3. 現段階の未確認事項・要判断

- 2025年度のGPX・CSV・QGIS原本の所在と、時刻付き軌跡の有無。
- 対象約1 kmの正確な範囲と比較する2経路の選定。
- OSMの歩道・横断歩道、PLATEAU対象モデルの欠損状況。
- 信号の再計測回数・時間帯・位相差の観測方法。
- 開発PCの性能、Unity実装環境・経験。
- 独立した検証用の歩行記録を確保できるか。
- シリアスゲーム／ゲーミフィケーションの最終的な学術的位置づけ。
- 先行研究の網羅的比較および指導教員による卒論としての到達基準。
