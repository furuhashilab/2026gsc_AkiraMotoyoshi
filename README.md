# 今、何から逃げたい？

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/)

都市の中で一時的に落ち着ける場所とルートを探す、スマートフォン向けWebアプリです。

## 何をするのか

利用者が「人混み」「騒音」「疲れ」「一人になりたい」など、今の状態を選びます。
青山・表参道・渋谷周辺の空間データから、5〜15分で歩ける「回復ルート」を推薦します。

目的地から探す一般的な地図ではなく、**今の気分から都市の過ごし方を探す**ことが特徴です。

## ゴール

- 30地点以上の「都市の余白」データを作成する
- 6種類の状態に対応する回復ルートを作成する
- スマートフォンで使えるWebアプリを完成させる
- GitHub Pagesで公開する
- 10〜20人に利用してもらい、使いやすさと実用性を検証する
- アプリ、データ、評価結果、卒業論文を成果物として提出する

## 成果物

1. スマートフォン向けWebアプリ
2. 都市の余白データセット（地点・評価・写真・観察メモ）
3. 状態別の回復ルート
4. 利用者アンケートと検証結果
5. 卒業論文・発表資料

## 使用ツール

- ChatGPT / Codex：設計、データ整理、分類、実装、分析
- Googleスプレッドシート：地点データの管理
- OpenStreetMap / 国土地理院地図：位置・地図情報
- HTML / CSS / JavaScript：Webアプリの制作
- Leaflet / GeoJSON：地図とルートの表示
- GitHub Pages：Web公開

## 完成までのステップ

### 1. 調査する場所と状態を決める

青山・表参道・渋谷を対象地域にします。利用者の状態は「人混み」「騒音」「疲れ」「一人になりたい」「暑さ」「気分転換」の6種類にします。

### 2. 都市の余白を記録する

公園、ベンチ、植栽のある道、静かな路地などを現地調査します。各地点について、位置、写真、観察メモ、静けさ、座りやすさ、人目、緑、駅からの距離を記録します。

### 3. データと推薦方法を作る

30地点以上のデータを整理し、AIを使って観察メモを分類します。その後、「疲れた人には座れる場所」「騒音から逃げたい人には大通りから離れた場所」のように、状態と場所を結びつける推薦ルールを作ります。

### 4. アプリを作る

利用者が状態と歩ける時間を選ぶと、おすすめの場所と5〜15分の回復ルートが表示されるWebアプリを制作します。地図、ルート、写真、推薦理由を実装します。

### 5. 公開して使ってもらう

GitHub Pagesでアプリを公開し、スマートフォンで使える状態にします。10〜20人に実際に使ってもらい、探しやすさ、面白さ、歩いた後の気分の変化をアンケートで確認します。

### 6. 改善して提出する

アンケート結果をもとに、評価項目、推薦ルール、画面を改善します。最終的に、Webアプリ、データセット、利用者評価、卒業論文、発表資料を完成させます。

### 完成の判断

「状態を選ぶ → ルートが表示される → 実際に歩ける → 利用後に評価できる」という一連の流れが、スマートフォンで問題なく使えれば完成です。

## 研究の問い

感情や状態を起点に都市空間を推薦することで、一般的な地図検索よりも、自分に合った一時的な回復空間を見つけやすくなるのか。
